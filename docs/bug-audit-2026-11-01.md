# mono bug audit — 2026-11-01

Snapshot reviewed: commit `6f42b70`. This preserves the original correctness
audit. The fix status and current verification are recorded below. Findings concern compositor behavior,
window management, configuration, IPC, and build correctness.

## Verification and limits

- Reviewed all 34 tracked files at the snapshot above.
- The normal build and animation regression suite pass.
- A build and regression run with XWayland disabled pass.
- AddressSanitizer and UndefinedBehaviorSanitizer exposed issues missed by the
  normal assertions; the sanitized suite is therefore not a clean pass.
- Used temporary fixtures and isolated headless compositors with real Wayland
  clients for the reproductions; production source was unchanged.
- Physical monitor hotplug, real input devices, and GPU reset recovery still
  need hardware testing. Passing the current tests does not cover those paths.
- Test fixtures and logs were created under `/tmp/mono-audit-*`; they are
  temporary evidence and are not required to build the repository.

## Fix status — 2026-11-01

All 23 findings have code fixes in the working tree. Performance optimizations
from the separate review are deferred. Original source line numbers above refer
to the audited snapshot, not the edited files.

| ID | Fix | Regression evidence |
| --- | --- | --- |
| B01 | Require a non-NULL monitor before canvas placement during mapping. | A real XDG client maps and closes with zero headless outputs. |
| B02 | Traverse leaves through existing parent links instead of fixed 512-entry arrays; prune without a capped stale list. | A 600-client tree is arranged and then pruned; sanitizer coverage. |
| B03 | Migrate only clients belonging to the closed monitor; choose an enabled replacement by actually iterating monitors. Center transferred geometry relative to the usable-area origin. | Unrelated floating geometry stays unchanged; a disabled first candidate is skipped. |
| B04 | Save normal geometry on entry to fullscreen, preserve it across repeated requests and monitor transfers, restore on exit. | Fixture tests cover repeated requests and monitor transfer; a live client restores 320x240. |
| B05 | Watch a symlink target's directory and basename so inode replacement does not orphan the watch. | Direct save, atomic replacement, another save, failed parse, and symlink retargeting. |
| B06 | Center canvas windows by updating world coordinates; use usable-area origins for normal floating windows. | Centering assertions with a nonzero monitor origin, reserved panel space, pan, and zoom. |
| B07 | Clear pending shortcut repeat while locked. | A repeated binding cannot change gaps while locked. |
| B08 | Apply a bare numeric tag selection even when `!` disables history toggling. | Client request assertions and live `monomsg -s -t '!0'`. |
| B09 | Reject an empty masked tag selection before modifying history. | IPC fixture and live attempt to remove the last viewed tag. |
| B10 | Give output subscriptions a lifetime independent of their manager resource. | Real wire events and child requests continue after manager release; monitor detach and output release are checked. |
| B11 | Count clients on each tag instead of emitting a boolean occupancy value. | IPC events report two clients on one tag. |
| B12 | Continue scanning occupied tags for urgent clients. | An urgent client behind a nonurgent client still produces urgent status. |
| B13 | Reinitialize logger verbosity after accepting a reloaded configuration. | Reload changes actual logger verbosity to the requested level. |
| B14 | Stop safely at a NULL scene parent and retain the node that owns layer-surface data. Do not pair an upper window's border with a lower window's surface. | Ownerless-node, layer-owner, and overlapping-border hit tests; undefined-behavior sanitizer. |
| B15 | Make generated protocol files depend on their XML inputs. | `make -n -W` schedules regeneration and dependent rebuilds for server and client XML. |
| B16 | Preserve WATCH mode when parsing `-F`. | The `-w -F` parser path reaches display connection in WATCH mode. |
| B17 | Pass NULL to `setlayout` when no index was supplied. | Two no-argument calls toggle the remembered layouts in both directions. |
| B18 | Include output name and tag in workspace IDs. If duplicate output names collide, omit the optional stable ID for that workspace. | Separate outputs keep identical visible names and distinct IDs; collisions do not advertise duplicate IDs. |
| B19 | Select constraints for the focused surface and seat; update on focus changes and constraint creation. Clear active ownership before potentially destructive deactivation. | Two-surface focus switching and activation/deactivation ownership assertions. Event delivery is simulated in this fixture. |
| B20 | Track all autostart batches in a dynamic list, prune expired groups on subsequent launches, and synchronize session creation before returning. | Forty live batches remain tracked; completed batches are pruned; immediate shutdown is exercised. |
| B21 | Premultiply parsed RGB channels by alpha; correct the translucent preselection constant too. | Reloaded translucent color channels match premultiplied values. |
| B22 | Keep output tests free of `asleep` changes and `updatemons` calls; clear sleep state only after a successful real commit. | A simulated backend test preserves sleep state, monitor geometry, and client assignment. |
| B23 | Keep explicitly selected output filters separate from the reported focused output. | An all-output watcher still subscribes when another output is announced after focus was reported. |

## Current verification

- `make check`: compositor/animation, parser, and monomsg regression suites.
- `make check-headless`: isolated live compositor tests with zero and one output;
  requires Python 3 and a working scenefx renderer. These do not take over the
  running desktop.
- Both checks also pass in a separate build with XWayland disabled.
- AddressSanitizer and UndefinedBehaviorSanitizer pass for `make check`, with
  leak detection disabled for the scene fixture and its external libraries.
- `git diff --check` passes.

Physical monitor hotplug, real pointer-confinement clients/devices, and hardware
output test/apply behavior still need desktop validation. The focused fixtures
check their state invariants; they do not emulate every backend or device.
